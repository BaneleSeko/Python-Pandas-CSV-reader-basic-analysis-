# Python-Pandas-CSV-reader-basic-analysis-

## Overview

This project demonstrates the use of Python and Pandas to read, inspect, analyse, filter, and export data.

The project was completed as part of an internship task to develop practical data analysis skills using Pandas and Jupyter Notebook.

## Objectives

The main objectives of this project are to:

- Read data from a CSV file using Pandas.
- Inspect the structure and contents of a dataset.
- Examine column names and data types.
- View the first and last records.
- Calculate basic summary statistics.
- Filter rows based on specific conditions.
- Select specific columns.
- Slice rows and columns from a DataFrame.
- Export filtered data to CSV and Excel files.

## Technologies Used

- Python
- Pandas
- Jupyter Notebook
- Visual Studio Code
